# Highway Roop — synchronized business page redesign

Static, responsive prototypes for:

- `drivetrain.html`
- `steering-suspension.html`
- `lightweighting.html`

Open `index.html` to switch between all three pages. The product content and imagery are retained; the surrounding storytelling sections use one shared design system.

## Design direction

- Shared hero, section rhythm, typography, container width and CTA language across all businesses.
- Capability cards turn long copy into a scannable connected system.
- A dark manufacturing-proof panel adds contrast and surfaces business-specific scale metrics.
- A common process rail makes each business route easy to compare without making the pages feel identical.
- Quality/validation, footprint and contact sections follow the same hierarchy across all three pages.
- All assets are stored locally in `assets/`; no build step or framework is required.

## Preview

Serve this folder with any static server, for example:

```powershell
npx serve .
```

Then open the local URL shown by the server.
