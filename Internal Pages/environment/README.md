# Highway Roop — Environment roadmap redesign

Responsive, standalone prototype for the “Carbon-neutrality roadmap” section.

## Preview

Open `index.html` directly, or run `node server.js` and visit `http://127.0.0.1:4173`.

## Files

- `index.html` — accessible content structure
- `styles.css` — responsive desktop/mobile presentation
- `script.js` — lightweight entrance animation with reduced-motion support
- `assets/highway-roop-logo.webp` — brand logo used in the preview header

The roadmap uses the preferred horizontal phase layout from the supplied reference, refined with homepage typography, cleaner spacing and a focused net-zero endpoint. It becomes a simple vertical timeline on mobile.
