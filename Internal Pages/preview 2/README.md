# Vision & Mission — Preview 2

Static responsive concept for Highway Roop's Vision, Mission and 3T3P values page.

Open `index.html` directly, or serve this folder with any static HTTP server.

## Direction

- Preserves the live Highway Roop typography, colour palette, container system, header, section navigation and spacing rhythm.
- Uses a distinct editorial concept from Preview 1: numbered Mission/Vision panels and an orbital 3T3P value index.
- Includes responsive navigation, scroll reveal effects, keyboard focus states and reduced-motion support.
